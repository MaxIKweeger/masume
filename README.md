# Makuuchi Manga

A fan-made companion site for the Aki Basho 2026 manga-style sumo ranking videos: daily bilingual (EN/JP) recaps, full bout lists, and Makuuchi standings with per-rikishi stats (form, fighting style, physical profile).

Unofficial fan project. Faces and characters are AI-generated manga illustrations; results and stats come from [sumo-api.com](https://sumo-api.com). Not affiliated with the Japan Sumo Association or NHK.

Hosted on GitHub Pages at **masume.com**.
